# 자동 스크롤 (Auto Scroll)

보상형 광고 앱처럼 "정해진 시간 동안 화면을 천천히 내려야 하는" 상황에서,
손가락 대신 화면을 쓸어내려 주는 안드로이드 앱입니다.

접근성(Accessibility) 제스처 기능으로 실제 손가락 스와이프와 같은 동작을 만들어 보내기 때문에
루팅이나 PC 연결 없이 폰 하나로 동작합니다.

---

## 무엇을 할 수 있나

| 기능 | 설명 |
| --- | --- |
| **속도 조절** | 한 번 쓸어내리는 데 걸리는 시간을 0.2 ~ 10초로 조절합니다. 길수록 천천히 내려갑니다. |
| **거리 조절** | 한 번에 넘기는 양을 화면 높이의 10 ~ 90%로 조절합니다. |
| **간격 조절** | 한 번 쓸어내린 뒤 다음 동작까지 쉬는 시간을 0 ~ 10초로 조절합니다. |
| **시간 조절** | 전체 실행 시간을 10초 ~ 30분으로 정하면 그 시간이 지날 때 자동으로 멈춥니다. `0`으로 두면 무제한입니다. |
| **시작 준비 시간** | 시작을 누른 뒤 보상 앱을 열 여유(0 ~ 15초)를 줍니다. |
| **방향 선택** | 아래로 / 위로 / **왕복** |
| **왕복** | 아래로 한 구간, 위로 한 구간을 되풀이합니다. 각 구간을 5초 ~ 5분으로 따로 정하며, 전체 실행 시간이 끝나면 멈춥니다. 아래 구간을 위 구간보다 길게 두면(예: 40초 / 20초) 조금씩 내려가면서도 계속 오르내려서 같은 영역을 벗어나지 않습니다. |
| **사람처럼 불규칙하게** | 거리·시간을 매번 ±20% 범위에서 흔들어 똑같은 간격의 기계적인 반복을 줄입니다. |
| **가로 기준선** | 화면을 가로지르는 줄을 한 줄 또는 두 줄 띄웁니다. 줄 오른쪽 끝의 둥근 손잡이를 끌어 원하는 높이에 맞추면, 화면이 올라가는 동안에도 보던 자리를 놓치지 않습니다. 조작 바의 줄 버튼으로 잠깐 감출 수 있습니다. |
| **떠 있는 조작 바** | 보상 앱 위에 작은 바가 떠서 **지금 향하는 방향(↓ ↑)** 과 남은 시간을 보여주고, 눌러서 바로 시작/정지할 수 있습니다. 왕복 중에는 화살표가 구간마다 뒤집히고 반대쪽이 흐리게 함께 보입니다. 드래그해서 위치를 옮길 수 있습니다. |

보상 앱은 보통 한 판이 끝나면 시간이 더 붙습니다.
그때는 조작 바의 ▶ 를 다시 누르면 설정한 시간만큼 다시 돌아갑니다.

## 설치하기

### 방법 1. 폰에서 바로 받기 (가장 쉬움)

폰 브라우저로 아래 주소를 열고 **AutoScroll-release.apk** 를 누르면 바로 내려받습니다.

**https://github.com/KwanghoJung01/Auto-scroll/releases/tag/latest**

이 `latest` 릴리스는 브랜치에 push 할 때마다 자동으로 최신 APK로 갱신됩니다.
버전을 따로 남기고 싶으면 `v1.0` 같은 태그를 push 하면 그 태그로도 릴리스가 만들어집니다.

```bash
git tag v1.0
git push origin v1.0
```

### 방법 2. 직접 빌드하기

Android Studio 로 열고 실행하거나, 터미널에서:

```bash
./gradlew assembleRelease
# 결과물: app/build/outputs/apk/release/app-release.apk
```

> 별도의 서명 키 없이도 바로 설치할 수 있도록 release 빌드도 디버그 키로 서명합니다.
> Play 스토어에 올릴 때에는 `app/build.gradle.kts` 에 본인의 서명 키를 넣어 주세요.

## 설치가 막힐 때 (대부분 여기서 걸립니다)

접근성 권한을 쓰는 앱은 스토어 밖에서 설치할 때 안드로이드가 두 번 막습니다.
앱 문제가 아니라 사이드로딩 정책이라, 아래 두 가지를 풀어주면 됩니다.

### "기기 보호를 위해 앱 차단됨" (Google Play 프로텍트)

1. **Play 스토어** → 오른쪽 위 **프로필 아이콘**
2. **Play 프로텍트** → 오른쪽 위 **⚙️ 설정**
3. **Play 프로텍트로 앱 스캔** 끄기 (있으면 *유해한 앱 감지 개선* 도 끄기)
4. APK 를 다시 눌러 설치

설치가 끝나면 Play 프로텍트를 **다시 켜두세요.** 켠 뒤 이 앱을 지우라는 경고가
뜰 수 있는데, 무시해도 계속 쓸 수 있습니다.

> 삼성 갤럭시의 **자동 차단(Auto Blocker)** 은 이것과 다른 기능입니다.
> 그것만 꺼서는 통과되지 않으니 위의 Play 프로텍트도 꺼야 합니다.

### 접근성 스위치가 회색이거나 "제한된 설정" 이라고 뜰 때

안드로이드 13 부터 스토어 밖에서 설치한 앱은 접근성을 기본으로 막아둡니다.

1. **설정 → 애플리케이션 → 자동 스크롤**
2. 오른쪽 위 **⋮ (점 세 개)**
3. **제한된 설정 허용**
4. 다시 **설정 → 접근성 → 설치된 앱 → 자동 스크롤 → 켜기**

---

## 처음 한 번 설정

1. 앱을 엽니다.
2. **접근성 서비스** 옆 `권한 주기` → 설정 → 접근성 → 설치된 앱 → **자동 스크롤** 켜기
3. **다른 앱 위에 표시** 옆 `권한 주기` → 허용
4. 속도·거리·간격·시간을 취향대로 맞춥니다. (값은 자동 저장됩니다)

## 쓰는 법

1. 앱에서 **시작** 을 누릅니다. 앱 화면이 닫히고 작은 조작 바가 뜹니다.
2. 준비 시간(기본 5초) 안에 보상 앱을 엽니다.
3. 설정한 시간 동안 자동으로 스크롤되고, 시간이 끝나면 멈춥니다.
4. 조작 바의 ▶ / ■ 로 언제든 다시 시작하거나 멈출 수 있습니다.
5. 조작 바의 ✕ 또는 알림창의 **종료** 를 누르면 완전히 끝납니다.

### 잘 안 될 때

- **화면이 안 움직여요** → 접근성에서 자동 스크롤이 꺼졌을 수 있습니다. 다시 켜 주세요.
  (배터리 최적화에 걸려 꺼지기도 합니다. 설정 → 배터리 → 자동 스크롤 → 제한 없음)
- **너무 빨리 지나가요** → `속도`를 2초 이상으로, `거리`를 30% 아래로 낮춰 보세요.
- **조작 바가 스크롤을 막아요** → 조작 바를 드래그해 화면 위쪽 구석으로 옮겨 주세요.
  스와이프는 화면 한가운데를 지나갑니다.

## 친구에게 보내기

앱 안 **4. 나눠주기** 에서:

- `설치 파일(APK) 보내기` — 지금 깔려 있는 앱을 그대로 카카오톡·메일 등으로 전송합니다.
- `앱 링크 공유` — 이 저장소 주소를 공유합니다.

받는 쪽도 위의 **설치가 막힐 때** 와 **처음 한 번 설정** 을 똑같이 거쳐야 합니다.
Play 프로텍트 차단과 "제한된 설정" 두 군데에서 거의 항상 걸리니 미리 알려주세요.

## 만든 구조

```
app/src/main/java/com/jace/autoscroll/
├── MainActivity.kt        설정 화면 · 권한 안내 · 공유
├── ScrollConfig.kt        설정 값과 저장(SharedPreferences)
├── ScrollController.kt    언제 얼마나 쓸어내릴지 결정하는 두뇌
├── AutoScrollService.kt   접근성 서비스 — 실제 제스처를 보내는 손
└── OverlayService.kt      다른 앱 위에 뜨는 조작 바 + 알림
```

- **최소 안드로이드 버전**: 8.0 (API 26)
- 화면 내용을 읽거나 저장하지 않고, 인터넷도 쓰지 않습니다. 제스처를 보내는 데에만 접근성 권한을 씁니다.

## 알아두기

자동 조작을 금지하는 앱에서 쓰면 해당 서비스의 이용약관에 어긋날 수 있고,
계정 제한을 받을 수 있습니다. 사용 여부와 결과는 사용자 본인의 책임입니다.
